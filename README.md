# 六爻文王卦：起卦與解卦

網址：https://regulusab.github.io/liuyao/

以京房八宮納甲法裝卦，依《增刪卜易》、《卜筮正宗》、《黃金策》等古籍逐條列出判斷與原文出處，並附《周易》卦辭、動爻爻辭。

- 起卦：三錢搖卦、手動輸入、時間起卦（梅花易數年月日時法）、數字起卦（梅花易數物數法）
- 裝卦：本卦／變卦、八宮世代、世應、納甲、六親、六獸、伏神、旬空、月建日辰、四柱
- 時間：輸入時間視為當地地方平時；節氣依當地經度換算地方平時；零時換日；東經 70° 以西日柱干支進一位，日期不動
- 分享：結果寫入網址參數；可列印、下載 PDF
- 全部在瀏覽器內計算，不上傳資料

`source/` 為原始碼（`node source/build.mjs` 建置）與驗證程式；`source/tests/verify-result.txt` 為最近一次驗證結果。

第三方：astronomy-engine（MIT）、lunar-javascript（MIT）、html2canvas（MIT）。古籍原文取自維基文庫等公開網頁，各條均附連結。
